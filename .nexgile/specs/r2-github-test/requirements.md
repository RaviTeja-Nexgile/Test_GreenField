# Requirements: R2 GitHub Test

## Requirement 1: Greet a person

**User Story:** As a user, I want a greeting with my name, so that the app says hello to me.

### Acceptance Criteria

1. WHEN greet is called with a name THE SYSTEM SHALL return "Hello, <name>!"
2. WHEN greet is called with a name THE SYSTEM SHALL be able to shout it in capitals
